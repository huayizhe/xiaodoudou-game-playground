# 小豆豆的游戏广场

一个本地游戏合集 + 统一入口页。所有游戏都是独立单文件 HTML，双击就能玩，不依赖服务器。

## 目录结构

| 路径 | 说明 |
| --- | --- |
| `index.html` | 入口页（游戏广场）：卡片式游戏墙，点击进游戏、随时返回广场 |
| `xiaodou.html` | 小豆闯关记 · 横版闯关（10 关） |
| `pvz.html` | 植物大战僵尸 · 塔防策略 |
| `stickman.html` | 火柴人勇闯恶魔岛 · 动作格斗（10 章 100 关，连续闯关 + 三选一强化，自动锁敌 + Z X C V 四技能，手机横屏触控） |
| `assets/covers/` | 各游戏封面，由自动截图脚本生成 |
| `docs/` | 游戏设计文档（单文件 HTML，入口 `docs/index.html`） |
| `tools/make-covers.ps1` | 封面批量截图脚本（调用本机 Chrome / Edge 无头模式） |
| `tools/make-covers.cmd` | 双击运行的入口（已带执行策略绕过） |

## 打开

双击 `index.html`。游戏在页面内的全屏舞台打开，顶栏常驻「返回广场」。

### 火柴人百关规则

- 主入口「开始 / 继续闯关」从本关入口开始；每关胜利后轻结算、恢复生命，再从三项强化中选择一项，随后自动进入下一关。强化界面不限时，不选不会推进。
- 闯关继承生命、怒气、技能冷却和强化；失败只重试当前关。连续失败三次后可主动选择本关辅助，下一关不继承辅助效果。
- 「单关练习」按章节浏览已解锁关卡，使用满血与章节标准强化，最佳评级与时间独立记录，不覆盖闯关快照。
- 存档保留每关入口资源、构筑、累计统计和设置；中途退出后从本关入口恢复，不保存当前波次。旧五关存档仅迁移最高解锁，旧星级与最佳时间不迁移。
- 2026-11-25 难度版：普通关改为 1/2/3 只批次出怪（40 关后每批 3 只），普通敌人伤害 ×0.85；每波至少 1 远程 + 1 近战重装，第 4 章起再固定 1 功能位；精英扩展到第 2 章起第 3/7/9 关；击杀回血改为 4 杀 1%；新增 48× 伤害显示层、暴击红字 / 普通白字、28 项常规强化 + 2 项后备；大招怒气改为按出手、技能和击杀获取（普攻 1.4 / 技能 3.5 / 击杀 6），不再按命中个数叠加，并修复普攻/大招触发音与 AudioContext 挂起后无声。
- 同一 HTML 支持键盘与横屏触控。桌面右下角固定显示「闪」图标与空格闪避 CD；设置提供总声音、背景音乐 / 战斗音效独立开关、音乐音量与音效音量滑杆、减弱震屏 / 闪烁、触控尺寸与左右镜像。当前已完成桌面与触控浏览器模拟测试，真实 Android / iPhone、百关完整人工通关和最终数值平衡仍需继续实测。
- 移动端若刷新后仍是旧版，GitHub Pages 的 HTML 缓存通常约 10 分钟；优先打开带版本参数的地址（如 `stickman.html?v=20261125b`），或在浏览器里清除该站点数据后重开，而不是只点普通刷新。

### 手机怎么玩

同一份 `stickman.html` 自动识别触屏，不用另开副本：横屏后左下摇杆走位，右下是无影斩（大，图标「斩」）+ 旋风斩 / 裂地跃斩 / 裂空投（三小，以「斩」为圆心排一段 72° 的圆弧，Z 最低、X 中间、C 最高），再往左一颗「闪」是闪避；整组控件离屏幕四边留出短边 5% 左右的边距，不贴边框。进关卡会尝试全屏并锁横屏；系统不允许时不会挡屏，竖屏下界面照常加载，只在画面下方挂一条「建议横屏」的轻提示。想强制预览手机布局可在桌面浏览器加 `?touch=1`。

## 新增一款游戏

1. 把新的 `xxx.html` 放到项目根目录。
2. 在 `tools/make-covers.ps1` 的 `$Games` 名单里加一行：`File` 文件名、`Slug` 封面名、`Crop` 可选裁剪区域。
3. 双击 `tools\make-covers.cmd` 生成封面到 `assets/covers/`。
4. 在广场页复制一张卡片，改 `data-file`、`data-title`、`data-cat`、封面 `src` 和文案即可。

## 版本管理约定

- 提交前先看 `git status`、`git diff`，确认改的是想改的内容。
- **没做完的游戏照常提交**，提交信息前缀写 `WIP:`，完成后再补一次正常提交，历史里能看清哪一版还没收尾。
- 一版收尾后打标签，方便回退：`git tag v1.0`。
- 封面图属于产物，一起入库；临时截图（`_*.png`、`_pwtest/*.png`）已加入 `.gitignore`。
- **改完就发布**：提交并 `push origin main` 后，GitHub Pages 会自动构建（一般 20–60 秒）；用线上地址确认新版生效再算完成。
