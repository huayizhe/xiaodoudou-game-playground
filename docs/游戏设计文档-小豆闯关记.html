小豆闯关记

十关横版闯关，一个人、一条命三颗心。本文记录现有实现的玩法骨架、关卡内容、数值口径和工程结构，作为后续改关、调难度、加新机制的对照基准。

01游戏概览

《小豆闯关记》是「小豆豆的游戏广场」里的横版闯关项目：10 个关卡线性推进，主角小豆从蘑菇草原一路打到魔王王座。全部玩法写在一个 HTML 文件里，用 Canvas 2D 逐帧手绘，没有外部图片、字体或脚本依赖，双击即开；在广场页里则以全屏舞台加载，外层顶栏负责「返回广场」。

文件小豆闯关记.html，3048 行，单文件自包含
技术形态原生 JS + Canvas 2D；固定逻辑分辨率 1000×560，按容器比例缩放
关卡尺寸瓦片 40×40，可见 25 列 × 14 行；单关 96–112 列（3840–4480 px，约 4 屏）
操作设备键盘（← → / 空格 / X）与触屏虚拟按键
单关时长熟练 1–2 分钟，首次探索 2–4 分钟
目标用户8–12 岁儿童与陪玩家长；难度以「能过、但需要试两次」为基准
进度保存localStorage 三个键：声音、最高分、每关星级
一句话定位：用十个短关卡把「跑、跳、踩、顶、吃道具、打魔王」六个动作依次教会，再用金币收集率给表现打分。

02设计目标与体验支柱

这款游戏不是靠堆敌人数量制造难度，而是靠四条支柱撑起体验，改动任何系统前都应先确认没有破坏它们。

支柱一：跳跃手感优先

手感参数是按「容错」设计的，不是按真实物理。跳跃输入有 0.14 秒缓冲，落地前 0.10 秒仍可起跳（土狼时间）；上升中松开跳跃键会立刻把速度削到 340，实现「短按小跳、长按高跳」。空中转向的加速度给到 1.9 倍，让玩家在半空修正落点。

支柱二：一关一个新机制

十关依次引入：基础跑跳 → 带刺敌人与火焰弹 → 空中跳岛 → 冰面惯性 → 岩浆与魔王 → 脆砖与横向浮板 → 尖刺与弹簧 → 黑暗视野与快速蝙蝠 → 横向风力 → 五血魔王。每个机制都在关卡开场提示里用一句话说明，不靠玩家自己悟。

支柱三：金币就是评分

每关只有一个评级维度：金币收集率。达到 85% 给三星、55% 给两星，其余一星。这让「速通」和「探索」形成取舍——想拿三星就必须绕路去吃高处的金币，而高处往往靠近危险区。

支柱四：死亡代价可控

每关 3 条命，过关后进入下一关补 1 条（上限 5）。死亡只回退到最近的存档点，不整关重来；脆砖在复活时自动复原，避免「死在废墟里」的死锁。

边界：不做联机、不做随机生成关卡、不做道具背包。关卡是纯静态数据，保证同一关每次打开都完全一致，方便家长和孩子反复练。

03核心循环

一关的循环固定为三段：读地形 → 变强 → 交旗。三段之间的时间比例大约是 5 : 2 : 1。

第一段 · 探索

从左往右推进，读三种信息：地面断口（坑）、上方砖块排列（金币与问号砖位置）、敌人站位。玩家此时只有小体型，一次接触就掉命，所以这一段的主要情绪是「小心」。

第二段 · 变强

顶到带蘑菇的问号砖变大，多挨一次伤害；顶到带火焰花的问号砖获得射击能力，按 X 发火焰弹。变强之后中段的设计会故意放宽，让玩家享受火力。

第三段 · 交旗

碰到旗杆即过关，按金币率结算星级。第 5、10 关的旗子被锁住，必须先打掉魔王（3 血 / 5 血），打完后旗子解锁并弹提示。

一次失败会发生什么

  1. 受伤：有体型时变小并获得 1.8 秒无敌，不掉命。
  2. 死亡：播放 1.3 秒坠落动画，扣 1 条命。
  3. 复活：回到已激活的存档点（未激活则回起点），体型重置为小，获得 1.5 秒无敌，脆砖全部复原。
  4. 命归零：本关结束，展示本关金币数与分数，可「再试一次」或「换一关」。

注意：复活会清空体型，但不会清空已收集的金币——金币按关累计，不会因为死亡而丢失，这是为了让低龄玩家不至于因一次失误丢掉整关的三星。

05玩家状态与生存规则

三种体型

状态碰撞盒能力受伤结果
small（小豆）26 × 38跑跳、踩怪、顶砖直接死亡
big（大蘑菇形态）30 × 52同上，多一次容错变小 + 1.8 s 无敌
fire（火焰形态）30 × 52同上 + X 发火焰弹退到 big 逻辑：直接变小

变身时碰撞盒高度变化会把脚底对齐（y -= 新高度 - 旧高度），避免变大时卡进地面或变小后悬空。火焰形态不叠加：吃到火焰花后即使再吃蘑菇也保持 fire。

伤害与生命的顺序

受击判定先查无敌帧，再看体型：有体型 → 变小；小体型 → 死亡。掉进坑（y > 画面高 + 80）和碰到岩浆直接死亡，不看体型，也不走无敌帧——这是唯一能秒杀大形态的规则。

08关卡设计意图与节奏

每关开场会在屏幕中央停留 2.85 秒，展示关号、关名与一句提示。提示文案就是这一关的教学目标，写关卡时先定提示，再定地形。

第 1 关 · 蘑菇草原“踩住小怪、顶问号砖吃蘑菇。”教学：移动、跳跃、踩踏、顶砖。全程只有 walker，地面连续、坑宽 3 格，失败成本最低。
第 2 关 · 潮湿洞穴“刺刺怪不能踩！顶出火焰花用火焰弹。”教学：识别不可踩敌人、获取并使用远程手段。用升降台把金币吊到高空，教玩家「等板」。
第 3 关 · 天空浮岛“脚下常常是云海！”教学：连续跳跃与落点判断。地面只剩首尾两段，中间全靠 4 格宽的砖岛，掉下去即死。
第 4 关 · 冰冻雪原“地上结冰了！跳的时候要提前一点点按。”教学：惯性。减速降到 250，玩家必须提前刹车；配合 slider 高速冲撞形成「滑行躲避」。
第 5 关 · 魔王城堡“踩它或打它 3 次，旗子才会打开。”首次出现魔王与岩浆。四段 2 格宽岩浆坑要求起跳点精准；魔王 3 血，打完解锁旗子。
第 6 关 · 沙丘遗迹“脆砖踩一下就会塌，要快快跑过去。”教学：时间压力。三段脆砖桥脚下一步就塌，必须连续跑跳；中段加横向浮板，练「在移动平台上起跳」。
第 7 关 · 熔岩工坊“地上有尖刺，红色踏板会把你弹上天。”教学：垂直节奏。五段岩浆 + 四组尖刺把地面切成碎片，弹簧是唯一稳定越过高墙的手段。
第 8 关 · 夜森林“森林里好黑，只有身边一小圈亮着。”教学：信息受限下的预判。视野收窄到角色周围，蝙蝠速度 112，逼迫玩家「听节奏跳」。
第 9 关 · 黄昏风谷“大风会把你往左吹，跳远要多留一点力。”教学：外力补偿。空中恒定 −32 的风，向右跳的落点整体左移；两块横向浮板横跨断口。
第 10 关 · 魔王王座“最后的魔王有 5 颗心，还会叫小怪帮忙。”终局：岩浆 + 尖刺 + 弹簧全上；魔王 5 血，每 3.6 秒召唤小怪（场上少于 3 只时），血量 ≤2 提速。

难度曲线

整体是「台阶式」而不是「斜坡式」：每关引入一个新机制时，前 30% 的路段只放这一种机制的简单版本，中段组合，尾段加一个消耗点（魔王或长跳）。第 4、7、9 关是三个明显的难度台阶——冰面、尖刺+岩浆、风力，都是「同一套操作、不同的物理反馈」，而不是新增按键。

背景音乐是一段 16 步旋律（[0,2,4,7,4,2,0,-3,0,4,7,9,7,4,0,-5] 半音偏移，基频 330 Hz），每 360 ms 走一步，每 4 步叠一个低八度根音。只在 playing / clear 状态推进，暂停时静默。

音量：目前只有「开/关」两档，没有滑杆。音效音量在 0.045–0.08 之间，已经压低以避免儿童长时间游玩时过响。

11UI 流程与状态机

外层只有两种「屏幕」：开始页与游戏页；游戏中通过状态机切换七个覆盖层面板。

state含义进入方式离开方式
start标题页初次加载开始游戏 / 选关
playing正常游戏开始、继续、复活暂停 / 死亡 / 过关
pause暂停面板Esc 或暂停按钮继续 / 重开 / 选关 / 帮助
select选关网格选关按钮点关卡或返回
dying死亡动画生命耗尽前的一次死亡1.3 s 后自动复活或结束
clear过关结算碰到旗子下一关 / 选关
over生命耗尽扣完最后一条命再试一次 / 换一关
end全部通关第 10 关结算重新开始
HUD 常驻

左上：生命心、金币 已收/总数、第 N 关与推进条（按玩家 x 与旗杆位置换算百分比）。右上：分数、声音开关、暂停。进度条只在 playing 时更新。

覆盖层

开始、选关、暂停、帮助、过关、失败、结局共 7 个。切换时统一隐藏其余面板，避免多层叠加；打开面板会清空方向键状态，防止回来时角色「自己往前跑」。

选关网格不设解锁门槛：十关全部可直接进入，星级只记录成绩。这是刻意设计——孩子卡在第 7 关时，可以先跳到第 3 关找回信心，而不是被锁死。

12存档与数据

键类型内容写入时机
xd.sound字符串1 / 0切换声音开关
xd.best字符串数字历史最高分过关且刷新纪录
xd.starsJSON 数组10 个 0–3 的整数每次过关

读档时会校验数组类型，解析失败直接重置为空表，不会因为一条脏数据导致整个游戏打不开。localStorage 不可用（隐私模式、文件协议受限）时全部静默降级：可以正常玩，只是不记录进度，也不报错。

分数在 startLevel（开始、选关、重开）时归零；点「下一关」继续时不清零，所以最高分记录的是「一轮」的最高分——可能跨多关，但不是十关总和，也不是单关成绩。如果以后要做总榜，需要在「从头开始」和「继续」之间明确口径。

13已知问题与迭代建议

问题影响建议
关卡数据是手写列坐标加一关要手工排 30+ 个砖块与金币，易错位抽成独立 JSON，配一个可视化关卡编辑器（拖格子导出）
星级只看金币高手可以低速刷币拿三星，缺少「打得漂亮」的维度增加「无伤」或「通关时间」第二维度，三星要求双条件
魔王只有 2 关终局内容偏薄，第 5 关魔王与第 10 关打法高度相似给第 5 关魔王加「砸地落石」，第 10 关加「三段跳扑」
火焰弹同屏 3 发对空战几乎无压力，第 9 关飞行敌人可站桩清改为按冷却限制而非数量限制，或让 flyer 有闪避
最高分口径是「从开始/重开起的一轮分」可能跨多关，与单关成绩、十关总分都不等价，玩家不容易理解明确为「十关总分」，或在结算页同时显示本关分与累计分
音效无滑杆、无音量记忆细分只能全开或全关，公共场合不便加 0–100 的音量档并记忆
触屏无暂停入口手机上只能靠 Esc（不存在），必须退回广场在触屏 HUD 补一个暂停按钮
复活清空体型第 8、9 关死后重新找火焰花，节奏被打断存档点复活时保留一次体型，或存档点附近固定放一朵火焰花
优先级建议：先做「关卡数据外置 + 编辑器」，它决定后面所有内容的产能；再做「星级第二维度」，它决定重玩价值；魔王扩展与触屏暂停可以随版本迭代。

A2附录：关卡数据字段

字段必填说明
name / theme是关名与主题键（须存在于 PAL）
cols是关卡总列数，长度 = cols × 40 px
hint是开场提示文案，一关一句话说清新机制
start / cp / flag是起点、存档点（列+行）、旗杆列
ground是地面段数组 [[起,止],…]，段间即坑
tiles否[列,行,类型] 或 [列,行,'q','mushroom']
coins否[列,行] 数组，决定星级分母
enemies否{t, col, row}，row 缺省为地面行
lava否岩浆段 [[起,止],…]，接触即死
platforms否浮板：纵向给 minY/maxY，横向给 axis:'x' 与 minX/maxX
physics否覆盖 accel / dec / airAcc（冰面用）
wind否空中横向风，正值向右；第 9 关为 −32
dark否开启黑暗视野遮罩
boss否{col, min, max, hp, final}；存在即锁旗

新增一关的最小步骤：在 LEVELS 末尾加一条数据（含 name/theme/cols/hint/start/cp/flag/ground），必要时在 PAL 加一套主题色，然后刷新页面即可从选关进入。不需要改引擎代码。
